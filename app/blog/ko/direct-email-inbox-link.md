## 이메일 주소 링크로 임시 받은편지함 바로 열기

새 탭이나 브라우저를 다시 연 뒤, 또는 저장한 메모에서 같은 임시 받은편지함으로 돌아가야 할 때가 있습니다. cleanorapi.com에서는 전체 임시 이메일 주소가 포함된 바로가기 링크를 사용해 주소를 다시 만들지 않고 받은편지함을 열 수 있습니다.

### 바로가기 링크 형식

다음 형식을 사용하세요.

`https://cleanorapi.com/inbox/your-address@bestinter.top`

예시 주소를 열고 싶은 전체 임시 주소로 바꾸면 됩니다. 해당 주소는 cleanorapi.com에서 현재 지원하는 수신 도메인을 사용해야 합니다.

링크를 열면 사이트가 주소를 검증하고 정규화한 뒤 현재 브라우저의 서명된 세션에 저장하고 홈 받은편지함으로 이동시킵니다. 이후 도착한 새 메일은 일반적인 받은편지함 새로고침 과정에서 표시됩니다.

### 유용한 상황

바로가기 링크는 다음과 같은 경우에 편리합니다.

- 짧은 프로젝트 동안 임시 받은편지함을 북마크하기
- 주소를 다시 복사하지 않고 탭 사이를 이동하기
- 일회성 다운로드나 저위험 인증에 사용한 받은편지함으로 돌아가기
- 필요한 경우 일회용 받은편지함을 협업자와 의도적으로 공유하기

반복 작업을 줄여 주지만, 임시 메일을 영구 계정으로 바꾸는 기능은 아닙니다.

### 24시간 세션 이해하기

링크를 열면 주소가 현재의 서명된 브라우저 세션에 등록되고 새로운 24시간 접근 기간이 시작됩니다. 바로가기 링크를 다시 방문하면 주소가 다시 등록되고 세션 기간도 새로 시작될 수 있습니다.

링크 자체는 일회용이 아니며 처음 연 뒤 자동으로 만료되지 않습니다. 중요한 코드, 영수증 또는 활성화 정보는 즉시 저장하고 받은편지함을 장기 보관소처럼 사용하지 마세요.

### 이메일 주소 자체가 접근 열쇠입니다

바로가기 링크에는 비밀번호나 비밀 token이 없습니다. 전체 이메일 주소를 알거나 추측한 사람은 같은 URL을 만들어 받은편지함을 열 수 있습니다.

따라서 다음 용도로 사용하지 마세요.

- 은행, 결제, 세금 또는 법률 관련 메일
- 중요한 계정의 비밀번호 복구
- 업무 신원이나 기밀 문서
- 반드시 비공개로 유지해야 하는 정보

URL은 브라우저 기록, 스크린샷, 서버 로그 또는 전달된 메시지에 남을 수도 있습니다. 접근 권한을 의도적으로 공유하려는 경우에만 링크를 전달하세요.

### 잘못된 주소는 거부됩니다

cleanorapi.com는 설정된 도메인의 올바른 형식 주소만 허용합니다. 지원하지 않는 도메인, 잘못된 로컬 부분 또는 불완전한 주소는 찾을 수 없음 응답을 반환하며 세션에 저장되지 않습니다.

### 실용적인 사용 흐름

임시 주소를 만들거나 선택한 뒤 바로가기 링크를 복사하고, 현재의 짧은 작업 동안만 보관하세요. 메일을 기다리는 동안 받은편지함을 새로고침하고, 필요한 정보를 받으면 즉시 저장한 뒤 작업이 끝나면 주소 사용을 중단하세요.

바로가기 링크는 임시 받은편지함을 다시 여는 과정을 간단하게 해 줍니다. 계정 복구나 비밀 유지보다 편의성이 중요한 단기 저위험 통신에 가장 적합합니다.
